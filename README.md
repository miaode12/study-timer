# 📚 学习计时器 (Study Timer)

SillyTavern 第三方扩展 —— 集成学习计时、番茄钟、正计时、每日统计与 AI 角色互动。

## 功能

- ⏱ **倒计时模式**：设定科目和分钟数，倒计时结束后自动记录
- ▶ **正计时模式**：不限时长，自由记录学习时间
- 📊 **每日/每周统计**：按科目汇总，进度条可视化
- 🎯 **目标追踪**：可配置各科目每日目标，自动计算完成率
- 🤖 **AI 角色互动**：计时开始/结束时自动让角色发言（支持 AI 生成消息或固定模板）
- 🎉 **里程碑庆祝**：达到 8/9/10/11 小时自动触发角色赞美
- 💬 **斜杠命令**：`/study`、`/study-forward`、`/study-stats` 等
- 🔧 **工具调用**：AI 可通过 function call 查询真实学习数据
- 🎨 **浮动面板**：可拖拽的底部控制栏

## 安装

### 方法一：GitHub URL 安装（推荐）

1. 在 SillyTavern 中打开 **扩展管理** 面板
2. 点击 **安装扩展**
3. 输入本仓库的 GitHub URL
4. 确认安装

### 方法二：手动安装

将本仓库所有文件放入 `public/scripts/extensions/third-party/study-timer/` 目录，刷新页面即可。

## 使用

### 面板操作

- 点击左下角 ⏱ 浮动按钮打开控制面板
- 选择科目 → 点击快捷分钟按钮开始倒计时
- 点击 **正计时** 开始不限时计时
- 📊 查看统计 | 🕐 查看当前时间 | 🤖 切换 AI 消息模式

### 斜杠命令

| 命令 | 说明 |
|------|------|
| `/study 数学 30` | 开始 30 分钟数学倒计时 |
| `/study-forward 数学` | 开始数学正计时 |
| `/timer-stop` | 停止当前计时 |
| `/timer-pause` / `/timer-resume` | 暂停/恢复 |
| `/timer-status` | 查看计时状态 |
| `/study-stats` | 查看统计报告 |
| `/study-now` | 查看当前时间 |

## 配置

在 `扩展设置 → 学习计时器` 中可自定义：

- 每日学习目标（默认 480 分钟）
- 各科目目标分钟数
- 计时消息模板（支持 `{{time}}` `{{subject}}` 等变量）
- 里程碑消息
- AI 生成消息开关
